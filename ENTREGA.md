## Descripción del proceso
Se creó el repositorio localmente inicializando Git con `git init`. Se organizó la estructura del recetario digital con la carpeta `proyecto` y sus archivos de texto. Luego se vinculó el repositorio remoto en GitHub. Se planteó una mejora mediante una Issue, la cual se desarrolló en una rama secundaria `mejora-readme`. Finalmente, se integró la mejora con una Pull Request y se sincronizó el repositorio local.

## Dificultades encontradas
No se presentaron dificultades críticas. Se comprendió de forma clara la dinámica de trabajo con ramas, creación de issues y solicitudes de extracción (pull requests).

## Reflexión final
El aprendizaje de Git y GitHub resulta fundamental para mantener un historial ordenado de cambios y estructurar proyectos digitales colaborativos con documentación clara.
