# Recetario Digital de Panadería Artesanal

## Descripción
Este proyecto es un compendio digital de recetas tradicionales de panadería y técnicas de horneado para consulta rápida y organizada.

## Objetivo
Organizar, gestionar y documentar un conjunto de preparaciones artesanales aplicando control de versiones con Git y GitHub.

## Estructura del repositorio
- `README.md`: Documentación e información general del proyecto.
- `ENTREGA.md`: Registro del proceso de trabajo y enlaces de la entrega.
- `proyecto/`:
  - `recetas.txt`: Lista de recetas principales de panadería.
  - `consejos.txt`: Guía básica de temperatura y horneado.
